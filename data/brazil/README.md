# Brazil UAP Leaks / Releases

This directory will contain material from Brazilian government, military, or police UAP-related leaks and official releases.

## Current Status

**Placeholder only.** No material has been added yet.

## Expected Structure

The Brazil adapter (`tools/ingest_brazil.py`) automatically discovers cases by scanning subdirectories under `data/brazil/`.

```
data/brazil/
├── <case_id>/                  # One folder per incident or batch
│   ├── video1.mp4
│   ├── video2.mov
│   ├── frame_001.jpg
│   └── metadata.json           # Optional: timestamps, region, notes, etc.
├── README.md
└── brazil_review_queue.jsonl   # Generated by ingest_brazil.py (normalized)
```

The recommended way to run ingestion is now:

```bash
uap-ingest brazil --input data/brazil --output data/brazil/brazil_review_queue.jsonl
```

With useful flags:
- `--dry-run` — preview what would be ingested
- `--verbose` / `-v` — more output

The old script `tools/ingest_brazil.py` still works for development but the CLI is the supported interface.

## metadata.json Schema

Each case folder can contain a `metadata.json` file. This is the preferred way to attach structured information to a case.

A template is available at:
`data/brazil/metadata.template.json`

### Recommended Schema

```json
{
  "case_id": "kebab-case-unique-id (required)",
  "title": "Human readable title",
  "date": "YYYY-MM-DD or approximate (e.g. 1977-10)",
  "location": {
    "region": "Primary region (e.g. Colares, São Paulo)",
    "city": "City or town (optional)",
    "coordinates": "lat,lon (optional)"
  },
  "event_type": "sighting | encounter | landing | abduction | mass sighting | physical effects | other",
  "summary": "Short 1-3 sentence description",
  "witnesses": "Number or description (e.g. 5, 'dozens')",
  "media": {
    "videos": ["filename.mp4"],
    "images": ["photo.jpg"],
    "other": ["document.pdf"]
  },
  "source": {
    "original_source": "Brazil UFO Leaks | etc.",
    "credibility_notes": "Any notes on reliability",
    "registry_id": "Optional link to sources.json"
  },
  "tags": ["array", "of", "tags"],
  "notes": "Freeform notes and observations",
  "review_status": "pending | reviewed | needs_more_info | low_quality"
}
```

### Full Example

A complete example is available at:
`data/brazil/examples/colares-1977.metadata.json`

This is based on the well-known Colares 1977 case and can be used as a reference when creating new cases.

## Important Notes

- Brazilian footage often has very different characteristics than DOD gun-camera or FLIR footage (different sensors, heavy compression, different lighting conditions, possible re-encoding).
- Do **not** reuse DOD V3 thresholds blindly. Source-specific configuration will be required.
- Provenance and credibility assessment is especially important for leaked material.
